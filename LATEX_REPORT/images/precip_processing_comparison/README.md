# Precip model processing comparison — CLEAN solo runs (2020-2023)

Cross-model comparison figures for the 4 CLEAN precip models (NLL, CRPS, WIND, FT-CRPS).
Copied (PNGs only) from `CLEAN_trained_models/precip_processing_comparison/` on branch
`CLEAN_SOLO_RUNS_2020-2023`; generated there by `scripts/overlay_wetfreq_histograms.py`,
`compare_precip_models.py`, and `fig_skill_timeseries.py` from each run's evaluation
outputs. Collected here for the report; the underlying `.json`/`.md` result tables stay
with the runs.

| File | Generated by | What it shows | Regime |
|------|--------------|---------------|--------|
| `wetfreq_threshold_histograms_overlay.png` | `scripts/overlay_wetfreq_histograms.py` | Daily-accumulation histograms (log density) and wet-day exceedance frequency P(accum >= t), observed vs all 4 models; broken x-axis: left 2/3 zooms on [0, p98], right 1/3 shows the tail | CV 2020-2023 |
| `wetfreq_threshold_histograms_overlay_2024.png` | `scripts/overlay_wetfreq_histograms.py` | Same as above on the holdout year | 2024 holdout |
| `physical_metrics_comparison.png` | `compare_precip_models.py` | Held-out physical metrics per model (MAE, wet-day frequency, SDII, Spearman), bar pairs CV vs 2024, black bar = observed | CV 2020-2023 + 2024 holdout |
| `training_comparison.png` | `compare_precip_models.py` | Fold-averaged training curves (held-out CRPS, MAE, Pearson, Spearman, train loss); NLL/CRPS/WIND from scratch, FT-CRPS warm-started from NLL (dashed, epoch axis not comparable) | CV 2020-2023 |
| `skill_timeseries.png` | `fig_skill_timeseries.py` | Domain-mean daily precip time series (MeteoSwiss, ERA5-Land, models; 30-day rolling mean) plus pooled MAE bars with skill vs ERA5-Land | CV 2020-2023 |
| `skill_timeseries_2024.png` | `fig_skill_timeseries.py` | Same as above on the holdout year | 2024 holdout |
