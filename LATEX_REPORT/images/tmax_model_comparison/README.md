Cross-model comparison figures. Copied (PNGs only) from
`CLEAN_trained_models/tmax_model_comparison/` on branch `CLEAN_SOLO_RUNS_2020-2023`;
generated there by `scripts/overlay_tmax_distributions.py` and `compare_evaluations.py`.
Collected here for the report; the CSV/JSON/MD metric tables and the `.npz` curve data stay

Each `-clip60` run sits next to the 30-epoch run it should be read against; that pairing is
the experiment. **The clipped runs win on every headline metric** — CV grid MAE 1.055
(`atm+wind-clip60`) and 1.088 (`atm-clip60`) against 1.308 and 1.239 unclipped — and they
**flip the wind verdict**: unclipped, wind was 0.069 °C MAE worse than plain z,t,q; clipped,
it is 0.033 °C better. The earlier "wind hurts" reading was a training-budget artifact.

The distribution overlay comes in both flavours: `tmax_distribution_overlay*.png` for the
original five, `tmax_distribution_overlay_with_clip60*.png` for all seven. Clipping tightens
the hot tail as well as the mean — P(Tmax >= 30 °C) on CV, against an observed 0.0140, goes
0.0171 → 0.0152 for wind and 0.0161 → 0.0123 for atm. That reverses the reading from the
5-model figure, where every atmospheric model ran warm in the tail.

Both regimes follow the tmax evaluation split: **CV 2020-2023** scores each day with the one

## Reading the calibration overlay

`PIT = Phi((truth - mu)/sigma)`; a calibrated model makes it Uniform(0,1), i.e. a flat
histogram. A U-shaped histogram means sigma is too small (overconfident), a dome means too
large. The plain Q-Q panel cannot separate these models — at ~68 M points every curve hugs
the diagonal — so the middle panel plots the same curves as a deviation from it, which is
where they separate.

**The good / decent / poor bands sit on the deviation panel, not on the density.** The
deviation is in probability units (0.05 means the model's stated 80th percentile is really
its 75th) and its maximum is exactly the KS distance, which is printed per model in that
panel's legend. The cut points (0.02, 0.05) are rules of thumb, not a standard. They are
deliberately *not* placed on the PIT-density axis: that density integrates to 1 over [0,1],
so a bin above 1 forces another below it, and "bad at PIT = 0.5" is not a statement that
stands alone. Significance testing is no use at this sample size — with 68 M points any
deviation rejects uniformity — so what is banded is effect size. The histogram axis is a
log ratio scale centred on 1x, so a density of 1.25x and one of 0.8x read as the same size
of error; its limits are fixed across both regimes so CV and 2024 can be read against
each other.

KS distance (max |deviation|), lower is better:

| | CV | 2024 |
|---|---|---|
| atm | 0.056 | 0.096 |
| atm-clip60 | 0.054 | **0.053** |
| atm+wind | 0.052 | 0.080 |
| atm+wind-clip60 | **0.030** | 0.098 |
| atm+sfcanchors | 0.076 | 0.076 |
| sfc | 0.034 | 0.058 |
| sfc-nogeo | 0.041 | 0.064 |

Note KS and z-std disagree for `atm+wind-clip60` on CV: it has the *best* KS (0.030) and the
*worst* z-std (1.078). They measure different things — KS is the largest cumulative
displacement, z-std is the spread. A model can track the uniform CDF closely overall while
still having systematically narrow intervals. `atm-clip60` is the only run that holds up on
the holdout (KS 0.053).

**Quote the 2024 figure for any calibration claim about the delivered system.** CV scores a
single fold's sigma; only the holdout year carries the moment-matched 5-fold ensemble sigma
(`sigma^2 = mean sigma_k^2 + var mu_k`) that the system actually produces. The two regimes
say different things here, and that is the point:

| z-std (ideal 1) | CV | 2024 | | coverage@90 (ideal 0.90) | CV | 2024 |
|---|---|---|---|---|---|---|
| atm | 0.927 | 0.839 | | atm | 0.925 | 0.944 |
| atm-clip60 | 1.038 | 0.887 | | atm-clip60 | 0.898 | 0.932 |
| atm+wind | 1.006 | 0.860 | | atm+wind | 0.908 | 0.940 |
| atm+wind-clip60 | 1.078 | 0.899 | | atm+wind-clip60 | 0.886 | 0.930 |
| atm+sfcanchors | 0.975 | 0.864 | | atm+sfcanchors | 0.913 | 0.937 |
| sfc | 0.991 | 0.963 | | sfc | 0.905 | 0.910 |
| sfc-nogeo | 0.947 | 0.911 | | sfc-nogeo | 0.919 | 0.923 |

On CV the single-fold sigmas are close to right, and the clipped runs are the *most*
overconfident (`atm+wind-clip60` z-std 1.078, coverage 88.6 %) — they cut the error without
shrinking sigma to match. On 2024 every model flips to underconfident (z-std < 1, coverage
> 90 %) because ensembling adds the between-fold spread `var mu_k` on top. The surface
models are least affected, which is why `sfc` is the best-calibrated run on the holdout
(z-std 0.963, coverage 91.0 %) despite having the worst accuracy. **Accuracy and
calibration rank these models differently — again.**

## One colour language across every figure here

Hue is the **input family**, identical in the bar charts and the distribution overlays, so
a model looks the same wherever it appears: blue = z,t,q; aqua = z,t,q,u,v; violet =
z,t,q + t2m/tp anchors; orange = surface. The **variant** within a family — the clipped
60-epoch retrain, or surface-without-geopotential — is a dashed line in the overlays and a
hatched bar in the bar charts, never a second shade of the same hue (that version was
measurably unreadable: its worst pair sat at OKLab ΔE 13.2, under the 15 floor). Four hues
is the most that clears the all-pairs colour gates, which is why the variant is a texture
rather than a fifth colour.

In the bar charts the x-axis already names the model, so colour is free to carry model
identity and the **hatch marks the regime** (plain = CV 2020-2023, hatched = 2024 holdout).
The definitions live once in `compare_evaluations.MODEL_STYLE`; the overlay script imports
them, so the two cannot drift apart.

## Grid vs station figures — do not cross-read them

`regime_comparison.png` scores the full 88 800-point MeteoSwiss gridded analysis;
`station_regime_comparison.png` scores 28 NBCN point observations (40 908 station-days on CV,
10 248 on 2024). Point observations carry representativeness error the smoothed gridded
product does not, so station MAE (~1.6 °C) sits well above gridded MAE (~1.2-1.45 °C) for
every model. The two figures also use *different* ERA5 baselines — 2.560 °C on the grid,
4.378 °C at stations — so their skill numbers are not on the same scale either. A reader
comparing grid skill 0.64 against station skill 0.73 would wrongly conclude the model does
better at stations. Compare models *within* each figure only.

Pooled station skill is additionally inflated because the ERA5 baseline is raw bilinear
`t2m_max` with no lapse-rate correction, which is enormous at alpine stations. The black
dashes in panel 3 are `skill_lowland` (stations below 1000 m) — the honest number.

## On the skill panels

Skill is comparable across all five models. The bilinear-ERA5 reference is shared — verified
bit-identical on CV, equal to 3e-05 °C on 2024 — because `era5_reference_degC` samples the
same ERA5-Land surface tmax file at the same targets for every model, whichever input grid the
model itself uses. `compare_evaluations.py` re-derives each model's reference as
`crps / (1 − skill)` on every run and relabels the panel if they ever diverge. Note that skill
is then a monotone rescaling of CRPS by a shared constant, so it ranks the models identically
to the CRPS panel — quote it for the "how much better than interpolated ERA5" framing, not as
independent evidence.

## Reading the distribution overlay

This is the tmax counterpart of `precip_processing_comparison/wetfreq_threshold_histograms_overlay.png`.
Two things differ, both deliberate:

- **The model curves are analytic, not sampled.** The pooled predictive law of a Gaussian
  head is the equal-weight mixture over all (day, grid point) pairs, so the density is
  `mean_k N(t; mu_k, sigma_k)` and the exceedance is `mean_k Phi((mu_k - t)/sigma_k)`.
  Precip had to sample because its left panel mixes a point mass at zero with a Gamma body.
- **No broken x-axis.** Daily tmax is two-tailed and not heavy-tailed, so one continuous
  axis with a log y-scale already shows both tails; there is no compressed tail to split off.

The third panel exists because the first two are almost uninformative on their own: every
model reproduces the marginal distribution so closely that the curves overlap. The ratio to
observed is where they separate. It is drawn only where the observed density rests on enough
samples (>= 5e-5) to be a reference. Observed curves use every valid (day, point); the
mixture curves use a spatial stride of ~1.6M pairs, and the script prints the
strided-vs-full observed deviation as a check.
